# Task Tracker Chrome Extension

A lightweight Chrome Extension that helps users manage daily tasks directly from the browser.

---

## Features

• Add tasks with due date and priority
• Categorize tasks (Work, Personal, Fitness)
• Mark tasks as completed
• Progress bar to track task completion
• Search tasks instantly
• Light and Dark theme toggle
• Browser notifications for overdue tasks
• Nested subtasks

---

## Technologies Used

HTML
CSS
JavaScript
Chrome Extension API
Chrome Storage API

---

## Installation

1. Download or clone this repository.
2. Open Google Chrome.
3. Go to chrome://extensions/.
4. Enable Developer Mode (top right).
5. Click Load unpacked.
6. Select the project folder.

The extension will appear in the browser toolbar.
